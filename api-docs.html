API reference

Build against the Gatita API

A compact reference for authentication, request shape, and the public chat completions endpoint.

Quick start

  1. Create an API key in the dashboard.
  2. Send `Authorization: Bearer gsk_...` with JSON requests.
  3. POST to `/ask-api/chat/completions` with `model` and `messages`.

Authentication

API requests use bearer keys. Browser-only pages still require session auth.

Authorization: Bearer gsk_your_key_here

Chat completions

POST /ask-api/chat/completions

{
  "model": "gatita-6.0",
  "messages": [
    { "role": "user", "content": "ping" }
  ],
  "temperature": 0.7,
  "max_tokens": 64,
  "stream": false
}

Errors

  • 401 Missing or invalid API key.
  • 403 Account banned, active strikes, or model restrictions.
  • 429 Rate limit exceeded.
