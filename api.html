How Strikes Work

  • Strikes are issued for policy violations (spam, abuse, prohibited content)
  • Free tier: Active strikes block API access entirely
  • Plus/Pro tiers: Strikes don't block API access (bypass enabled)
  • Strikes expire after 30 days of good behavior
  • 3+ active strikes may result in account suspension
  • Appeal strikes via Discord support
